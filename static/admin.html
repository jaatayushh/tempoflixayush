To authenticate with the streaming API, include your API key in the X-API-Key request header or as query parameter ?api_key=YOUR_KEY.

cURL Request
curl -H "X-API-Key: YOUR_KEY" \
  "https://api.ayush.ai.studio/api/search?q=batman"
JavaScript (Fetch)
const res = await fetch("/api/search?q=batman", {
  headers: { "X-API-Key": "YOUR_KEY" }
});

Python (Requests)
import requests
headers = {"X-API-Key": "YOUR_KEY"}
res = requests.get(
  "https://api.ayush.ai.studio/api/search?q=batman",
  headers=headers
).json()
